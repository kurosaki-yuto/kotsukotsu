# こつこつ使い方ガイド — AIへの頼み方・タスクの砕かせ方

こつこつは「ゴール起点のToDo・実行管理ツール」です。自分のAI(Claude等)をMCPで接続すると、AIがこつこつを直接読み書きしながら仕事を進めてくれます。このガイドは、その AIへの正しい頼み方 をまとめたものです。

## 大原則: タスクを「投げる」のではなく「砕かせる」

AIにゴールを渡しただけで放置すると、ゴールが大きいまま止まります。こつこつのAIには最初から「ゴールを実行可能なタスクに砕く」仕組みが入っています。使い方は簡単で、頼み方を変えるだけです。

悪い頼み方:
「新規顧客獲得のタスク入れといて」
→ 大きいゴールが1個できて終わり。誰も動けない。

良い頼み方:
「新規顧客獲得のゴールを、実行できるタスクに砕いて登録して」
→ AIがゴール配下に [AI] / [人+AI] / [人] のサブタスクを1個ずつ登録し、どれから動くかまで提案してくる。

## 3分類の意味

AIが登録するサブタスクには必ず頭にプレフィックスが付きます。

- [AI] — AI単独で完結するもの (調査・下書き・コード・整理)。「これ進めて」と言えばAIがそのままやる。
- [人+AI] — AIが準備して人が判断・仕上げするもの。
- [人] — 人にしかできないもの (電話・対面・金銭判断・最終承認)。

自分宛の [人] タスクが増えていたら、それが「あなたの番」の合図です。

## よく使う頼み方テンプレ

- 現状把握: 「今日やるべきことを教えて」「◯◯のゴールの現状まとめて」
- 分解: 「このゴールを実行可能なタスクに砕いて登録して」
- 実行: 「[AI]のタスクを上から進めて」
- 相談: 「◯◯のタスク、何がブロッカーか整理して」
- 記録: 「今の進捗をコメントに残しておいて」

ポイント: 「〜しといて」で終わらせず、「砕いて」「登録して」「進めて」まで言い切ると、AIはこつこつ上に形を残します。

## メンション (@) の使い方

- コメントで「@表示名」と書くと、その人に通知が飛びます (アプリ内通知+スマホプッシュ)。
- 表示名はメンバー一覧の名前をそのまま使ってください。名前の中のスペースは省略してもOKです (例: 「山田 太郎」さんは @山田太郎 でも届く)。
- 「@全員」で全メンバーに通知。
- AI経由で送る場合も同じ書き方でOK。AIに「◯◯さんにメンション付きでコメント残して」と頼めば正しく送られ、誰に通知が飛んだかまで確認できます。

## コメントの編集・取り消し

- 自分のコメントは後から編集・取り消しできます (コメントにマウスを乗せると右上にボタンが出ます)。
- AI経由で投稿したコメントも、AIに「さっきのコメント直して/消して」と頼めば編集・取り消しできます。
- 編集したコメントには「(編集済み)」が付きます。

## 書き方のルール (AIも人も共通)

- 現状(current_state): 1文=1行。今どこ/ブロッカー/次の一手 を空行で区切る。
- 完了の基準(completion_criteria): リード文 → 空行 → □チェック項目(1行1個)。やることリストは書かない (やることはサブタスクとして登録)。
- 1タスク=1アクション。「◯◯を検討」ではなく「◯◯のドラフトを作成しコメントに投稿」まで具体化。

## 困ったとき

- AIが何も砕いてくれない → 「実行可能なタスクに砕いてサブタスク登録して」と明示する。
- メンションが飛ばない → 表示名が合っているかメンバー一覧で確認 (AI経由なら notified が空かどうかで分かる)。
- AIが繋がらない → 設定 > APIキー のURLをコピペし直す (1文字欠けると繋がりません)。再発行すると今までのURLは無効になるので注意。
