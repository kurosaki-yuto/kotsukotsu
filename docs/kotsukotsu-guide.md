# こつこつ使い方ガイド — AI への頼み方

こつこつは「ゴール起点の ToDo・実行管理ツール」です。自分の AI (Claude / Claude Code / Codex など) を MCP で繋ぐと、AI がこつこつを直接読み書きしながら仕事を進めます。このガイドは、その頼み方をまとめたものです。

繋ぎ方は、アプリの 設定 → APIキー (接続用URL) と 設定 → 連携ガイド を見てください。連携ガイドの「AI にまとめて入れてもらう」を押すと、Claude Code がこつこつ・Notion・Chatwork・GitHub の接続とプラグインをまとめて入れます。

## 大原則: タスクを「投げる」のではなく「砕かせる」

AI にゴールを渡しただけで放置すると、ゴールが大きいまま止まります。

- 悪い頼み方: 「新規顧客獲得のタスク入れといて」 → 大きいゴールが1個できて終わり
- 良い頼み方: 「新規顧客獲得のゴールを、実行できるタスクに砕いて登録して」 → AI が配下に作業ステップを1個ずつ登録し、どれから動くかまで提案する

いちばん楽なのは、タスクを開いて「AIで進める」を押すことです。そのタスクの指示文が入った状態で AI が開くので、送信するだけで、読む → 砕く → 進める → 書き戻す まで進みます。

## どのタスクにも「完了の基準」と「現状」

こつこつは、親のゴールだけでなく小タスクにも次の2つを持たせます。人も AI も、これを読めば開いたその場で次の一手を選べます。

- **完了の基準**: 何が満たされたら終わりか。他人が ○× を付けられる形で、成果物名・数値・期日・確認方法のどれかを入れる。「検討する」「整える」は基準になりません
- **現状**: (1) 何日時点か (2) 済んだこと (確認した事実と数字) (3) ボール (次に動くのはこちらか先方か) (4) 残り・詰まり

AI は小タスクを作るときに完了の基準を1〜2行で入れ、終えたときに結果 (何をして、何が確認できたか、未確認は何か) を現状に残します。

## 担当と進行中

- タスク名に [AI] / [人+AI] / [人] のような区分は付けません。担当はアサインで表します。作った本人が自動で担当になります
- AI は手を動かす直前に、その一番下の小タスクを「進行中」にします。画面の橙の印で、誰のどの AI が何を進めているかが分かります

## よく使う頼み方

- 今日やること: 「今日やることを出して」(AI は list_my_tasks で、今日 → 期限切れ → 進行中 → 期限が近い の順に拾う)
- 予定を組む: タスク画面の「AIで今日の予定を組む」。タスクを見積もって Google カレンダーの空きに入れる。メンバーの名前を入れれば、その人たちの分も組める
- 現状を書き直す: 「◯◯のゴールの現状を、Chatwork とメールの直近を読んで書き直して」
- 分解: 「このゴールを実行可能なタスクに砕いて登録して」
- 詰まりの整理: 「◯◯のタスク、何がブロッカーか整理して」
- 記録: 「今の進捗をコメントに残しておいて」

「〜しといて」で終わらせず、「砕いて」「登録して」「進めて」「書き戻して」まで言い切ると、AI はこつこつ上に形を残します。

## メンション (@)

- コメントで「@表示名」と書くと、その人に通知が飛びます (アプリ内通知 + スマホのプッシュ)
- 姓だけ (@田中) やスペース抜き (@山田太郎) でも届きます。同じ姓が複数いるときはフルネームで
- 「@全員」で全メンバーに通知
- AI 経由でも同じ書き方で送れます。誰に通知が飛んだかは返り値の notified で分かります

## コメントの編集・取り消し

自分のコメントは後から編集・取り消しできます。AI 経由で投稿したものも、AI に「さっきのコメント直して / 消して」と頼めば直せます。

## 困ったとき

- AI が砕いてくれない → 「実行可能なタスクに砕いて登録して」と明示する。または「AIで進める」から始める
- AI がこつこつを読めない → 設定 → APIキー の接続用URLを繋ぎ直す。Claude Code なら /mcp でこつこつが出ているか確かめる
- スマホで「AIで進める」の指示文が入らない → 「ブラウザの Claude Code で進める」を使う (アプリに渡すと落ちることがある)
- メンションが飛ばない → 表示名がメンバー一覧と合っているか確かめる
